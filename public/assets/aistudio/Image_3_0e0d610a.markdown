## Brand & Style

This design system embodies the calculated precision of high-performance developer tooling combined with the atmospheric depth of advanced artificial intelligence research. Targeted at engineering leaders, technical recruiters, venture capitalists, and open-source collaborators, the interface projects authoritative technical mastery, visionary engineering rigor, and refined modern aesthetics.

The visual style synthesizes Linear-inspired micro-interactions, Vercel-grade typography disciplines, and refined dark glassmorphism. It rejects gratuitous sci-fi tropes in favor of structural clarity, deep spatial layering, and intentional kinetic feedback. High-frequency translucent surfaces sit over a deep cosmic canvas, articulated by razor-thin glowing gradients and crisp data layouts that make complex AI/ML architectures and full-stack engineering work effortlessly readable and memorable.

## Colors

The palette establishes an ultra-deep obsidian background punctuated by controlled optical luminescence. 

- **Canvas & Structure (Neutral `#080B12`):** Base canvas layer that eliminates screen glare while providing limitless contrast headroom. Nested tiers graduate through `#0E131F`, `#151C2C`, and translucent layers (`rgba(14, 19, 31, 0.75)`).
- **Core Engine (Primary Electric Blue `#3B82F6`):** The primary signal for active system states, primary interactions, interactive terminal tabs, and structural anchors.
- **Cognitive Layer (Secondary Violet `#8B5CF6`):** Applied to AI/ML context indicators, neural node visualizations, tags, and secondary action surfaces.
- **Photon Pulse (Tertiary Cyan `#22D3EE`):** Reserved for ultra-high-priority telemetry badges, runtime status indicators, live deployment nodes, and ambient edge glows.
- **Foreground Contrast:** Headings utilize `#F8FAFC`, primary body text uses `#94A3B8`, and subdued meta-information resides at `#475569`. Borders employ translucent white overlays (`rgba(255, 255, 255, 0.08)`) with dynamic gradient highlights.

## Typography

The typographic hierarchy is divided into three distinct roles:

- **Headings (Space Grotesk):** Provides architectural character and progressive engineering personality. Letter tracking is pulled tight to impart muscular compactness and structural presence.
- **Narrative & Explanation (Inter):** Maximizes readability across technical descriptions, project post-mortems, and architectural deep-dives. Clean vertical metrics ensure effortless skimming.
- **System Telemetry & Metadata (JetBrains Mono):** Drives commit hashes, benchmarks, technology stacks, terminal command lines, status indicators, and code samples. Rendered with uppercase styling and expanded tracking for micro-labels.

## Layout & Spacing

A 12-column responsive fluid grid anchors all page layouts within a max-width container of `1280px` (`80rem`), centered with dynamic safety margins. 

- **Desktop (1024px+):** 12 columns, 32px (`2rem`) gutters, minimum 64px (`4rem`) outer margin. Technical projects use asymmetrical 8:4 splits for architecture schematics and documentation sidecars.
- **Tablet (768px - 1023px):** 8 columns, 24px (`1.5rem`) gutters, 40px (`2.5rem`) outer margin. Dual-column project card layouts.
- **Mobile (< 768px):** 4 columns, 16px (`1rem`) gutters, 24px (`1.5rem`) outer margin. Stacks cleanly into vertical modular feeds with horizontal sub-scroll containers for code previews and skill badges.

Vertical rhythm adheres strictly to an 8px base module (`0.5rem`). Section spacing scales dynamically between `space-2xl` and `space-3xl` to preserve distinct narrative boundaries between portfolio domains.

## Elevation & Depth

Spatial layering relies on glassmorphism, dynamic backdrops, and luminous perimeter boundaries rather than opaque dropping shadows:

- **Base Void (`z-0`):** `#080B12` canvas layered with a radial micro-mesh gradient containing subtle `#3B82F60A` and `#8B5CF608` ambient blooms at screen coordinates.
- **Surface Level 1 (Static Cards & Containers):** Translucent fill `rgba(14, 19, 31, 0.65)` backed by `backdrop-filter: blur(16px) saturate(180%)`. Border is 1px solid `rgba(255, 255, 255, 0.08)`.
- **Surface Level 2 (Interactive Cards on Hover & Flyouts):** Translucent fill `rgba(21, 28, 44, 0.8)` with `backdrop-filter: blur(24px)`. Border transforms into a directional linear gradient: `linear-gradient(135deg, rgba(59, 130, 246, 0.5), rgba(139, 92, 246, 0.2) 60%, rgba(34, 211, 238, 0.4))`. Ambient glow: `box-shadow: 0 0 24px -4px rgba(59, 130, 246, 0.15)`.
- **Surface Level 3 (Modals, Command Palette & Floats):** Dark glass fill `rgba(8, 11, 18, 0.88)` with `backdrop-filter: blur(32px)`. Edge highlighted by `1px solid rgba(34, 211, 238, 0.3)` accompanied by a multi-tier halo: `box-shadow: 0 20px 48px -12px rgba(0, 0, 0, 0.8), 0 0 40px -8px rgba(34, 211, 238, 0.12)`.

## Shapes

The design system employs a calibrated modern roundedness (`Level 2`). Primary elements balance fluid tactile forms with engineered structure:

- Standard cards, interactive code containers, and technical modules utilize `rounded-lg` (`1rem` / 16px).
- Internal components, buttons, text fields, and micro-dialogs use standard `rounded` (`0.5rem` / 8px).
- Status badges, runtime indicators, and micro-pills use full circular boundaries (`rounded-full` / 9999px) to indicate continuous system states.
- Technical code snippets and terminal windows retain rigid structural stability via subtle `rounded-md` (`0.375rem` / 6px) corners.

## Components

### Buttons
- **Primary Action:** Solid electric blue (`#3B82F6`) fill with subtle vertical sheen (`linear-gradient(180deg, rgba(255,255,255,0.15) 0%, rgba(255,255,255,0) 100%)`). Text in `#FFFFFF` with medium weight. Hover triggers an energized cyan edge glow: `box-shadow: 0 0 20px rgba(59, 130, 246, 0.45)`.
- **Secondary (Glass):** Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.12)`. Hover shifts background to `rgba(255, 255, 255, 0.08)` and border to `rgba(139, 92, 246, 0.5)`.
- **Tertiary (Ghost Monospace):** Transparent background with `JetBrains Mono` text, displaying subtle chevron prefixes that slide 3px to the right on cursor hover.

### Chips & Badges
- **Tech Stack Pills:** Dark translucent fill `rgba(14, 19, 31, 0.8)`, border `1px solid rgba(255, 255, 255, 0.06)`, font `label-mono-sm`. Include subtle 6px colored indicator dots (e.g., PyTorch in `#8B5CF6`, TypeScript in `#3B82F6`, Live System in `#22D3EE`).
- **Telemetry Badges:** Capsule pill with a pulsing SVG live dot, cyan-tinted border, and text formatted in all-caps monospace.

### Cards & Project Showcases
- **Glass Spec Cards:** Rendered using Surface Level 1 glass. Include gradient sheen over the top border (`border-t`) transitioning from electric blue to violet.
- **Hover Kinetic States:** Translates `translate-y: -4px` smoothly (`cubic-bezier(0.16, 1, 0.3, 1)` over 250ms), elevating to Surface Level 2 with glowing perimeter outlines.

### Form Inputs & Search / Command Palette
- **Text Inputs:** Height 44px, background `rgba(8, 11, 18, 0.7)`, border `1px solid rgba(255, 255, 255, 0.1)`. Focus state applies a crisp outline: `border-color: #3B82F6` accompanied by `box-shadow: 0 0 0 2px rgba(59, 130, 246, 0.2)`. Placeholder text in muted `#475569`.
- **Selection Controls (Checkboxes & Radios):** Minimalist custom boxes styled with `rgba(255, 255, 255, 0.05)` fill and `1px solid rgba(255, 255, 255, 0.2)`. Checked state displays electric blue fill with sharp white vector checkmark.

### Technical & AI Additions
- **Interactive Terminal Windows:** Top header featuring window controls (red/yellow/green micro-dots), active branch badge, and copy-snippet trigger. Body set with JetBrains Mono (`code-block`), complete with syntax highlighting in cyan, violet, and electric blue.
- **Model Metric Gauges:** Compact micro-bars featuring vibrant linear gradient fills (`#3B82F6` to `#22D3EE`) overlaid across dark numeric grids for training accuracy, latency (ms), and compute benchmarks.
